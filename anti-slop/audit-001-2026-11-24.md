# antislop audit 001 (RESTU) - 2026-11-24

Mode: AFTER (session override). Scope: `index.php` (login), `includes/layout.php`, `assets/css/app.css`, `assets/js/app.js`, `admin/pengaturan.php`, `DESIGN.md`.
Method: code inspection plus contrast math. The app was NOT run in a browser for this audit, and dark mode was checked only by reading tokens.

Nothing has been changed. Pick numbers to fix.

## HIGH (Hard Gate)

1. **R-02 em dash in UI text (5 places).** `index.php:80` (login footer "APP — INSTANSI"), `admin/pengaturan.php:163, 189, 196, 206`. Fix: use a comma, colon, or `·`.
2. **R-39 missing landmarks.** `includes/layout.php`: the topbar is `<div class="topbar">` and the content is `<div class="page">`, so there is no `<header>` or `<main>`. Screen-reader users have no "skip to content" target. Fix: change those two tags (CSS classes stay).
3. **R-32 / R-39 nav dropdown not keyboard-complete.** `assets/js/app.js:76-89`: the toggle has no `aria-expanded`, and Escape does not close it. Fix: toggle `aria-expanded` and add a keydown Escape handler that returns focus to the toggle.
4. **R-32 weak focus on inputs.** `app.css:476, 949`: `outline: none` is replaced only by a 1.5px border going from grey to ink. That is hard to see, especially on select/textarea. Fix: add a `:focus-visible` ring (e.g. `box-shadow: 0 0 0 3px` of the accent).
5. **R-39 bell link name comes from `title` only.** `includes/layout.php` `.notif-bell`: the SVG is `aria-hidden` and the count is a bare number. Fix: add `aria-label="Notifikasi, N belum dibaca"`.
6. **R-37 / R-30 direction file is a brand clone.** `DESIGN.md` is "Design System Inspired by Mastercard" (MarkForMC, Mastercard colors, the eyebrow dot, a 4-column footer, pill everything). The rules require asking the owner: keep this as RESTU's direction (note the override), or rewrite `DESIGN.md` as RESTU's own direction (court office, approval workflow). The app already diverges (Sofia Sans, no 4-col footer), so the file and the app disagree.

## MEDIUM (Purpose-Gate)

7. **R-29 palette sprawl.** The core palette has ink, signal orange, and link blue, plus 7 stat-tile tones (blue, purple, teal, rose, amber, green, red). That is above 2-3 core colors plus 1 accent. Fix: map the tones to status meaning (success, warning, danger, neutral) and drop purple, teal, and rose unless each one encodes a distinct status.
8. **R-10 glass in two places.** The login card (`app.css:409`) and the calendar card plus lens (`app.css:1379, 1392`). Each is within the cap of 1-2 per screen, but neither reason is written in DESIGN.md. Fix: write one line of reason, or drop the login blur (the dark panel already gives contrast).

## LOW (Quality Locks)

9. **R-25 borderline contrast on stat numbers.** On light backgrounds, teal `#0e9678` on `#d2f2e8` is 3.11:1 and rose `#c4275e` on `#fbdce8` is 4.34:1. This passes only because `.num` is large text. If `.num` is ever under 18px, it fails. Fix: darken teal to about `#0a7a62`.
10. **R-31 no dial line.** DESIGN.md has no `Dial: ENERGY / RHYTHM / MOTION` line. Suggested for an internal office app: ENERGY 1 / RHYTHM 1 / MOTION 1-2.

## Checked, no finding
- `<html lang="id">`, a unique `<title>`, and viewport without zoom block: OK on login and layout.
- `prefers-reduced-motion`: honoured across the motion blocks.
- Theme toggle: has `aria-label`; its SVGs are `aria-hidden`.
- Calendar cell: `outline:none` replaced by the `.kal-halo` ring. OK.
- No fake stats, testimonials, FAQ, or ghost nav links (all nav comes from real routes).
